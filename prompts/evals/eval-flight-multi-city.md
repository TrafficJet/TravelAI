# eval-flight-multi-city — Мультигородской маршрут

## Сценарий
Пользователь хочет маршрут через несколько городов.

## Входящее сообщение
"Хочу полететь из Еревана в Барселону с остановкой в Стамбуле на 3 дня. Вылет 15 июля."

## Ожидаемое поведение
1. Бот видит: origin=Ереван (EVN), стопover=Стамбул (IST), destination=Барселона (BCN)
2. Бот НЕ переспрашивает origin — EVN явно указан
3. Бот вызывает search_flights для двух сегментов: EVN→IST и IST→BCN
4. Вызывает search_hotels для Стамбула (3 ночи) и Барселоны (кол-во ночей не указано → 3 ночи по умолчанию)
5. В ответе по отелям: "Нашёл отели на 3 ночи — скажи, если нужно другое количество"
6. Цены только в USD, не умножать на пассажиров
7. Если пересадки менее 90 минут — предупредить через check_journey_timing

## Критерии провала
- Переспросил "откуда летишь?" — ПРОВАЛ
- Вызвал search_hotels с неправильным кол-вом ночей без объяснения — ПРОВАЛ
- Не упомянул что ночи по умолчанию = 3 — ПРОВАЛ
- Не обработал два сегмента маршрута — ПРОВАЛ
