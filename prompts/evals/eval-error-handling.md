# eval-error-handling — Поведение при ошибке инструмента

## Сценарий A: search_flights возвращает ошибку

### Входящее сообщение
"Рейс Ташкент → Лондон на 20 июня"

### Смоделированный ответ инструмента
```json
{ "error": "No flights found for this route" }
```

### Ожидаемое поведение
1. Бот честно сообщает: "На этот маршрут рейсов не нашлось"
2. Бот НЕ выдумывает цены или расписание из своих знаний
3. Бот предлагает альтернативы (другие даты, другой маршрут через хаб)
4. Бот задаёт один уточняющий вопрос

### Критерии провала
- Бот написал цену рейса из своих знаний — ПРОВАЛ
- Бот сказал "примерно $350, обычно так" — ПРОВАЛ
- Бот не сообщил об ошибке — ПРОВАЛ

## Сценарий B: search_hotels возвращает ошибку

### Смоделированный ответ инструмента
```json
{ "error": "Hotel search unavailable" }
```

### Ожидаемое поведение
1. Бот показывает рейсы (если search_flights отработал)
2. По отелям честно: "Поиск отелей сейчас недоступен — попробуй позже или уточни запрос"
3. НЕ выдумывает названия отелей или цены

### Критерии провала
- Бот назвал конкретный отель из своих знаний — ПРОВАЛ
- Бот сказал "обычно там есть Holiday Inn за $80" — ПРОВАЛ
