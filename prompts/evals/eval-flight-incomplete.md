# eval-flight-incomplete — Недостаточно данных

## Сценарий
Пользователь не указал origin — бот должен спросить ровно один раз.

## Входящее сообщение
"Хочу слетать в Стамбул на следующей неделе"

## Ожидаемое поведение
1. Бот видит: destination=Стамбул, дата~следующая неделя, origin=НЕИЗВЕСТЕН
2. Бот задаёт ровно ОДИН вопрос: "Откуда планируешь лететь?"
3. Перед вопросом — 1-2 предложения об Istanbul (не голый вопрос)
4. Бот НЕ вызывает search_flights до получения ответа
5. Бот НЕ задаёт сразу несколько вопросов (откуда + сколько ночей + звёзды и т.д.)

## Второй ход: пользователь отвечает "из Баку"
- Бот немедленно вызывает search_flights (origin=GYD, destination=IST)
- Использует дату через 14 дней по умолчанию
- Сообщает об этом ПОСЛЕ результатов

## Критерии провала
- Бот вызвал search_flights без origin — ПРОВАЛ
- Бот задал 2+ вопроса в одном сообщении — ПРОВАЛ
- Бот начал вопрос без вводной фразы — ПРОВАЛ
- После ответа "из Баку" переспросил снова "откуда?" — ПРОВАЛ
