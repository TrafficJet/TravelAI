## ОТЛИЧИЕ GOOGLE PLAY ОТ APP STORE

В Google Play ключевые слова индексируются не из скрытого keywords-поля (его нет), а напрямую из:
1. Title (вес ×3)
2. Short Description (вес ×2)
3. Full Description (вес ×1, но плотность важна)

Стратегия: каждое приоритетное ключевое слово должно встречаться в описании 3–5 раз органически. Keyword density: 2–3% для топ-кластеров. Выше 5% — риск пенальти от NLP-алгоритма Google.

## КЛЮЧЕВЫЕ СЛОВА ДЛЯ ИНДЕКСАЦИИ В GOOGLE PLAY

В Google Play нет отдельного keywords-поля. Слова ниже должны быть органично вплетены в title, short description и full description с частотой 3–5 упоминаний для топ-кластеров.

### Топ-кластеры (встречаются в описании 3–5 раз)
| Кластер | Где встречается | Количество |
|---------|----------------|------------|
| авиабилеты / билеты | title, short, описание | 5 |
| отели / бронирование | title, short, описание | 5 |
| путешествие / путешествий | title, short, описание | 6 |
| AI / AI-помощник / AI-чат | title, short, описание | 5 |
| маршрут | subtitle, описание | 4 |
| чат | title, short, описание | 4 |

### Средний приоритет (2–3 упоминания)
- планирование, планировать
- поиск рейсов / рейс
- дешёвые / дешевле
- бюджет
- бронировать / бронь
- трансфер
- пересадки

### Хвостовые (1 упоминание, для long-tail индексации)
- itinerary / маршрут по дням
- нейросеть / нейросеть для путешествий
- AI travel-агент
- крипто-оплата / криптовалюта
- СНГ / Казахстан / Беларусь
