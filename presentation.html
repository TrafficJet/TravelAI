⚡ Quick Start
bash · ~/projects
# 1. Clone the repo
$ git clone https://github.com/org/travel-ai
$ cd travel-ai

# 2. Install dependencies
$ npm install

# 3. Configure environment
$ cp .env.example .env
  # add ANTHROPIC_API_KEY + DUFFEL_TOKEN

# 4. Start backend + mobile
$ npm run dev

✔ Backend running on :3000
✔ Expo DevTools ready — scan QR or press i/a
